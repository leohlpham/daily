# LifeHub

A personal all-in-one web app for iPhone (add to Home Screen): spending from bank CSVs (Up Bank and others), Outlook calendar with a Claude-powered day planner, Garmin/health tracking, and a +EV bet log with bookmaker hub. All data stays on the device (IndexedDB).

- `npm install && npm run dev` to run locally
- `npm run build` → static site in `dist/` (deployed to GitHub Pages by `.github/workflows/deploy.yml`)
